# Koh Chee Hoe — Game Designer Portfolio

A responsive static portfolio website.

## Open locally

Open `index.html` in a browser. For the most consistent behaviour, serve the folder with a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

The folder can be deployed as-is to GitHub Pages, Netlify, Cloudflare Pages, or any static web host.

## Main files

- `index.html` — page content
- `styles.css` — layout and visual design
- `script.js` — mobile navigation and reveal animation
- `assets/` — project images and unit sprites
- `Koh_Chee_Hoe_Game_Designer_Resume.docx` — downloadable résumé
