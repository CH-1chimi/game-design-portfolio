gumi Asia / Unit design & live operations

FINAL FANTASY BRAVE EXVIUS Global

I worked on unit design, combat balancing and recurring Global content releases, liaising with Square Enix on unit specifications and coordinating with marketing, art and localization.

Role
Game Designer, gumi Asia
Focus
Unit design, Global adaptation and publisher liaison
Delivery
Recurring Global content releases

My contribution

For most of the units featured in my portfolio, I reviewed the Japanese-version stats, adjusted values for the Global version and verified that the port worked correctly. The two versions had slight system differences, so matching data alone was not enough.

Publisher liaison & cross-functional collaboration

I liaised directly with Square Enix regarding unit specifications for FFBE Global. I also communicated with marketing, art and localization teams to support unit release preparation. These responsibilities complemented the design, configuration and validation work required for recurring live-service content.

Adapting content for Global

Compare the unit’s stats and behavior with its Japanese-version reference, then adjust values where required for the Global environment.

Implementation and release

Check that the port behaves as intended despite system variations between the two versions. Configuration and implementation checks are part of release validation.

How I approach unit adaptation

02 · AdaptAdjust values for the Global environment.

04 · ResolveInvestigate implementation issues and support release checks.
